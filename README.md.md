
# Day 01: Business Analytics with Excel

## Project Overview
A practical sales performance analysis using Microsoft Excel.

## Skills Practised
- Sales data organisation
- Revenue and cost calculations
- Gross profit analysis
- Profit margin analysis
- Product performance comparison
- Business insight development

## Key Results

| Metric | Result |
|---|---:|
| Total Revenue | BDT 305,900 |
| Total Cost | BDT 237,500 |
| Gross Profit | BDT 68,400 |
| Gross Margin | 22.36% |

## Key Findings
- Laptop generated the highest revenue.
- Laptop generated the highest gross profit.
- Mouse achieved the highest gross margin at 50%.

## Business Takeaway
Revenue and profitability are different performance
indicators. Management should consider both when
making product and marketing decisions.
